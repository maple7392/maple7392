闪连加速器 Mac 教程：DMG 安装、打开应用与连接

更新于 2026-11-09

Mac 下载的是 dmg 文件。先把应用正确装到电脑，再处理首次打开时的系统提示，最后登录和连接。遇到“打不开”，不用一上来就找终端命令。

先选你要完成的事

下载安装 · 首次连接 · 处理常见问题

1. 确认这台 Mac 的系统和芯片

点击屏幕左上角苹果菜单，打开“关于本机”，记下 macOS 版本和芯片类型。芯片可能显示 Apple M 系列，也可能是 Intel。需要向客服问兼容性时，把这两项一起提供。

本页 Mac 链接指向 闪连-1.3.0.dmg。安装包版本不等于系统兼容承诺；如果发布方没有写明支持你的机型，先确认再安装。

下载 Mac 安装包

2. 打开 DMG，把应用安装到“应用程序”

  1. 下载完成后，在 Safari 下载记录或 Finder 的“下载”文件夹中找到 dmg，双击打开。
  2. 如果窗口显示闪连图标和“应用程序”文件夹，将闪连拖入“应用程序”，等复制完成。如果显示的是安装器，则按安装器提示操作。
  3. 打开 Finder → 应用程序，从这里启动闪连。以后也从这里启动，不必每次重新双击 dmg。
  4. 确认应用已复制完成后，可以在 Finder 侧边栏推出安装磁盘。

容易弄混的地方：dmg 是装着应用的磁盘映像。仅打开这个文件，不一定已经把应用安装进“应用程序”。

3. 系统说不能打开，先看它到底说了什么

系统提示或现象处理顺序
下载自互联网，是否打开确认名称和来源，阅读提示后再决定。
无法验证开发者、无法检查是否含恶意软件先向发布方确认来源、签名和当前版本，再参照 Apple 对相应提示的说明处理，不要直接关闭 Gatekeeper。
提示包含恶意软件或会损坏电脑不要继续运行，也不要用命令移除安全标记；联系发布方获取可核实的版本。
提示应用已损坏先重新下载完整安装包，并确认系统与芯片要求。重复出现时反馈原话，不要把所有“损坏”都当成同一个原因。

按住 Control 点“打开”的旧方法，并不适用于所有 macOS 版本。优先查看当前系统“隐私与安全性”显示的具体说明。

4. 登录、查看时长，再连接线路

  1. 打开闪连并登录账号；如果原来在手机上使用，先试同一账号。
  2. 查看剩余时长和VIP状态。使用签到时长时，先选择有权限的免费线路。
  3. 按客户端提示选择线路并启动连接。出现添加VPN配置或网络扩展的系统请求时，先确认对应的是闪连，再按当前系统指引处理。
  4. 连接成功后，打开自己常用的网站或软件试一次。应用窗口显示连接成功，还需要实际任务正常才算这一步完成。

如果只有浏览器打不开，而其他软件正常，检查浏览器是否还启用了另一套代理扩展；不要在未分清原因前同时改DNS和系统代理。

5. 能打开但连不上，检查这三处

先看账号：时长是否到期、所选线路是否需要VIP。账户没问题，再换另一条有权限的线路。

再看本地网络：断开闪连后打开普通网页。如果断开也不能联网，先处理Wi-Fi或网络认证。

最后看重复配置：如果Mac还运行着其他代理或VPN客户端，先按它们自己的界面断开，避免几套配置叠加。记录改动后再试，不要直接删除不认识的网络服务。

仍然不行时，提供macOS版本、芯片、闪连版本、完整错误文字和出现时间，隐藏账号密码。

6. 退出和卸载时，别只删除 DMG

先断开线路，再从应用菜单退出。若程序附带卸载器，优先使用它；否则按Apple的应用卸载方式处理“应用程序”中的闪连。删掉“下载”文件夹里的dmg，只是删除安装文件。

如果曾手动添加过VPN配置，先确认名称，再到系统设置中检查是否需要移除。购买过订阅的，还要回原购买渠道检查续费状态；卸载软件不会自动取消付款安排。
